## はじめに

ヒスイ（翡翠）は東洋で **「玉（ぎょく）」** と呼ばれ、中国では金以上に尊ばれてきた緑の石。日本でも縄文時代から **勾玉や大珠** として用いられ、糸魚川産のヒスイは7000年以上前の遺跡からも出土しています。「徳・繁栄・長寿」という大切な価値の象徴として、東アジアで最も愛されてきたパワーストーンのひとつです。本記事では **鉱物データ・歴史背景・効果として語られていること・FAQ・編集後記** をまとめます。

## <span id="basic"></span>基本情報・鉱物データ

| 項目 | 内容 |
|---|---|
| 石名 | ヒスイ（翡翠） / Jade |
| 和名 | 翡翠（ひすい） |
| 鉱物種 | ジェダイト（硬玉）／ネフライト（軟玉） |
| 化学組成 | NaAlSi₂O₆（ジェダイト）／Ca₂(Mg,Fe)₅Si₈O₂₂(OH)₂（ネフライト） |
| 結晶系 | 単斜晶系 |
| 主な産地 | ミャンマー、グアテマラ、ロシア、日本（糸魚川・新潟） |
| モース硬度 | 6.5〜7（ジェダイト）／6〜6.5（ネフライト） |
| カラー | 緑、白、紫（ラベンダー）、黒、橙、赤 |
| 対応チャクラ | 第4（ハート） |
| 5月の誕生石 | ◯（追加指定） |

「ヒスイ」と呼ばれる石は鉱物学的に2種類あり、**特に高評価のジェダイト（硬玉）はミャンマー産** が最高品質。日本の糸魚川産は世界最古のヒスイ加工文化を持つ産地です。2016年には日本鉱物科学会が **「日本の国石」** にヒスイを選定しました。

## <span id="types"></span>ジェダイトとネフライトの違い

| 項目 | ジェダイト（硬玉） | ネフライト（軟玉） |
|---|---|---|
| 別名 | 本翡翠 | 軟玉 |
| 産地 | ミャンマーが主 | 中国・カナダ・ロシア |
| 硬度 | 6.5〜7 | 6〜6.5 |
| 価格 | 高価 | 比較的手頃 |
| 文化的価値 | 清朝以降の中国・日本で珍重 | 古代中国の玉文化の中心 |

中国古代の「**玉**」はネフライトを指し、清朝以降に **ジェダイトが「翡翠」として珍重** されるようになりました。

## <span id="meaning"></span>石言葉と歴史・文化背景

石言葉は「**長寿・繁栄・徳**」。

中国では古代から **「玉に5徳あり」**（仁・義・智・勇・潔）と語られ、皇帝・貴族の装身具や副葬品として最高位の石でした。日本では縄文時代から糸魚川のヒスイで **大珠・勾玉** が作られ、出雲大社など各地の遺跡からも出土しています。マヤ・アステカ文明でもグアテマラ産ジェダイトが神聖視され、東洋・中米の **両半球で独立に「最高の石」** とされた珍しい鉱物です。

> 出典: 日本鉱物科学会、GIA Jade Reference、各種考古学資料。

## <span id="faq"></span>よくある質問（FAQ）

**Q1. 「Aヒスイ」「Bヒスイ」「Cヒスイ」とは？**

A. ジェダイトの **処理レベルを示す業界用語**。Aは無処理の天然品、Bは樹脂含浸処理品、Cは染色品、B+Cは含浸＋染色。本物の天然ヒスイを購入したい場合は **「Aヒスイ」「無処理」「鑑別書付き」** を確認してください。

**Q2. ラベンダーヒスイは染色？**

A. **天然のラベンダー（紫）ヒスイ** は存在しますが、市場には染色品も多く流通しています。鑑別書で天然色か処理色かを確認するのが安心。

**Q3. 日本の糸魚川ヒスイは買える？**

A. はい。糸魚川市内の専門店や、新潟県主催のフェアなどで国産ヒスイを購入できます。日本ならではの **「国石」** を身近に楽しめるのが魅力です。

**Q4. 中国の「玉」と「翡翠」は同じ？**

A. 厳密には異なります。古代中国の「玉」は **ネフライト（軟玉）** を指し、清朝（18世紀以降）にミャンマー産の **ジェダイト（硬玉）** が「翡翠」として珍重されました。

**Q5. 繁栄・徳の石は他にもありますか？**

A. ルチルクォーツ・シトリン・タイガーアイ等が定番。詳しくは [目的別パワーストーン総合ガイド](/blog/luck-powerstones-complete-guide/) の金運の章へ。
