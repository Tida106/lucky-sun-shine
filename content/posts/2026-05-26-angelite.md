## はじめに

「**天使石（てんしせき）**」と呼ばれるアンジェライトは、**淡い空色のやわらかな色合い** が空に浮かぶ雲を思わせる、現代スピリチュアル界で **「天使との対話を助ける石」** として広く愛されているパワーストーン。**「優しさを引き出し、誠実な対話を支える」** お守りとして、人間関係に悩む方の手元に静かに寄り添います。

## <span id="basic"></span>基本情報・鉱物データ

| 項目 | 内容 |
|---|---|
| 石名 | アンジェライト（Angelite） |
| 和名 | 硬石膏（こうせっこう）／アンハイドライト |
| 鉱物種 | 硫酸カルシウム（無水石膏） |
| 結晶系 | 斜方晶系 |
| 主な産地 | ペルー、エジプト、リビア、メキシコ、ドイツ |
| モース硬度 | 3〜3.5（柔らかい部類） |
| 比重 | 2.90〜3.00 |
| 屈折率 | 1.569〜1.614 |
| カラー | 淡い空色〜水色（時に白を含む） |

アンジェライトは **硬石膏（アンハイドライト：CaSO₄）** という鉱物の **淡い青〜空色の変種** で、**ストロンチウムを微量含むことが青色の発色源** とされます。**セレナイト（透石膏：CaSO₄·2H₂O）** と同じカルシウム硫酸塩の仲間で、**「水分子を含まない」** ことがセレナイトとの最大の違いです。

「アンジェライト」という名前は **流通名・商品名** で、鉱物学的な正式名称ではありません。**1987年にペルーで青い硬石膏が発見** された際、その **空のような色合い** と **「天使（angel）を連想させる癒しの波動」** という象徴性から、商業的に「アンジェライト」と名付けられました。**ニューエイジ運動の文脈** から生まれた現代の流通名と理解する必要があります。

モース硬度3〜3.5は **宝石としては柔らかい部類** で、爪でも傷がつくレベル。**水に対しても弱い性質** があり、長時間の水浸しでは表面が劣化します。**「身につけるジュエリー」より「置く癒し石」** として迎えるのが、アンジェライトとの長い付き合いのコツです。

## <span id="meaning"></span>石言葉と歴史・文化背景

アンジェライトの石言葉は「**天使の守護・誠実な対話・優しさ・受容**」。

鉱物学的には **硬石膏（アンハイドライト）** として19世紀から知られていましたが、**「アンジェライト」という名で青い変種が広く流通するようになったのは1987年以降**。**ペルー** で発見されたこの淡い青色の石が、**「天使との対話を助ける石」** という象徴性で、急速に世界中のヒーリング界に広まりました。

**ニューエイジ運動** の文脈では、**「天使は人間と話したいと願っているが、人間の側が忙しすぎて気づけない」** という思想があり、**アンジェライトはその「気づき」を助ける石** とされてきました。**淡い空色** が **「天使が住むとされる空・雲の領域」** を視覚的に呼び起こし、**「上を見上げて、静かに耳を澄ます」** 感覚を支える――そういう象徴的な使われ方が、現代の人気を支えています。

日本では2000年代以降、**「天使・スピリチュアルブーム」** とともに広く知られるようになりました。**「自分を見守ってくれる存在を感じたい」「優しい対話を求めている」** といった現代的な心の動きと深く響き合う石として、現代まで愛され続けています。

## <span id="care"></span>浄化方法・お手入れ

アンジェライトは **モース硬度3〜3.5** で柔らかく、**水に対しても弱い** ため、繊細な扱いが必要です。

OK な浄化方法：

- **水晶クラスター・さざれ石の上に置く**：もっとも安全な定番浄化
- **ホワイトセージの煙にくぐらせる**：1〜2分で十分
- **月光浴**：満月の前後3日に窓辺へ
- **音叉・クリスタルチューナーで音浴**：金属に触れさせないなら有効

避けたい浄化方法：

- **水・流水**（**硬石膏は水分を吸収しやすく、表面が劣化する**）
- **粗塩**（湿気を吸って表面を破壊する可能性）
- **超音波洗浄機**（クラックが拡張する可能性）
- **直射日光に長時間さらす**（淡い青色は紫外線で退色のリスク）
- **湿気の多い場所での長期保管**（湿気が結晶構造を破壊）

日常のお手入れは、**柔らかい乾いた布で軽く拭く** だけが基本。**水洗いは絶対にしない** のがアンジェライトとの長い付き合いの絶対ルールです。

## <span id="fake"></span>天然・類似石の見分け方

- **天然アンジェライト** は **淡い空色のやわらかな色合い** で、**わずかな白っぽいムラ** が見えるのが自然な姿
- **セレナイトとの混同**：**同じカルシウム硫酸塩** で見た目が似ているが、**セレナイトは透明〜白の繊維状光沢**、アンジェライトは **淡い青の均質な質感**
- **染色マグネサイトとの混同**：マグネサイトを青く染色したものが「アンジェライト風」として流通することがある。**触感と比重** で見分け可能
- **ハウライトターコイズ（染色ハウライト）との混同**：染色ハウライトはより鮮やかな青、アンジェライトはより淡い空色――色合いで区別可能
- **ガラス模造**：プラスチック・ガラス製の模造品もある。**比重・冷たさ・触感** で本物と区別可能
- **鑑別書付き** を選ぶのが最も確実

「**アンジェライトを選ぶときの本質**」は **淡い空色の柔らかさ**。鮮やかすぎる青・人工的に均一すぎる色は、染色品や類似石を疑うサインです。

## <span id="faq"></span>よくある質問（FAQ）

**Q1. アンジェライトは何年くらい身につけられますか？**

A. モース硬度3〜3.5は **宝石としては柔らかい部類** で、爪でも傷がつくレベルです。**強い衝撃・摩擦・水を避けて丁寧に扱えば** 数年単位で楽しめますが、**ダイヤモンドやサファイアのように世代を超えて受け継ぐ** タイプの石ではありません。**「数年単位のお守り」** として割り切るのが現実的な付き合い方です。

**Q2. お風呂・プール・スポーツで着けたまま大丈夫？**

A. **すべてNG** と考えてください。**水に対して致命的に弱い** ため、お湯・プール・温泉・スポーツ時の汗――どれもアンジェライトを劣化させます。**「水を一切近づけない」** がアンジェライトの絶対ルールです。

**Q3. アンジェライトとセレナイト、どちらが「天使系」に強いですか？**

A. **両方とも「天使系のヒーリングストーン」** として語られますが、**性格が異なる** とされます：
- **アンジェライト**：**淡い空色**。**「天使との対話・コミュニケーション」** を支える
- **セレナイト**：**透明な月の女神の石**。**「他の石を浄化する力」** を持つ
**用途次第** で選ぶのが正解で、**両方をペアで持つ** 愛用者も多くいます。

**Q4. アンジェライトは「天使と話せる」石ですか？**

A. **スピリチュアルな象徴性** として広く語られる効能ですが、**医学的・科学的に検証されたものではありません**。**「自分を見守ってくれる存在を感じたい」「上を見上げて静かな時間を持ちたい」** ――そんな気持ちを支える **お守り** として迎えるのが、本来の付き合い方です。

**Q5. アンジェライトとハウライトターコイズ（染色ハウライト）の違いは？**

A. **アンジェライト** は **天然の淡い空色の硬石膏**、**ハウライトターコイズ** は **白いハウライトを青く染色したもの**。鉱物として全くの別物です。**色合いの違い**（アンジェライトはより淡い、染色ハウライトはより鮮やか）、**質感の違い**（アンジェライトは均質、染色ハウライトは網目模様）で区別できます。

**Q6. アンジェライトのアクセサリーが欠けた・水で劣化した場合は？**

A. パワーストーンの世界では「**身代わりになってくれた**」と捉える伝統があります。柔らかく繊細な石なので、欠けや劣化は珍しいことではありません。感謝を込めて土に還す・引き出しに丁寧にしまうのが一般的です。**価格帯が手頃** なので、新しい石を迎えやすいのもアンジェライトの良い点です。

アンジェライトは「**派手な石**」ではありません。けれど、**淡い空色の存在感が、毎日の景色を少し優しくしてくれる**――そんな、現代を生きる私たちに必要な癒しを運んでくれる石だと思います。
